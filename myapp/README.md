# React Image Gallery - IMGSCAPE

A responsive React image gallery using reusable components, props, map(), filtering, CSS Grid, React Fragments, and responsive CSS.

## Run

1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Open a terminal in the project folder.
4. Run:

npm install

5. Then:

npm run dev

6. Open the localhost URL shown by Vite.

## Components

- Header.jsx
- Gallery.jsx
- ImageCard.jsx
- Footer.jsx

Images are stored in an array of objects in Gallery.jsx. Add another object to automatically create another card.
